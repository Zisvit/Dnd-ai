## Ключевые компоненты

### 1. Система типов задач (TaskType)
**Файл:** `dndai/core/task_types.py`
- `TaskType.SIMPLE` → FAST модели — compress, dice
- `TaskType.NARRATIVE` → BALANCED модели — основной геймплей
- `TaskType.COMPLEX` → SMART модели — планирование
- `TIER_FOR_COLOR`: игровые категории «красный»/«жёлтый»/«синий» переопределяют tier

### 2. Маршрутизация провайдеров
**Файл:** `dndai/api/openrouter.py` → `_iter_providers_for_task()`
- Выбирает провайдеров/модели в зависимости от TaskType
- Fallback цепочка: tier модели → ниже tier → остальные провайдеры
- Ретраи только для восстановимых ошибок (429/5xx/сеть); 400/404 — сразу дальше
- Стриминг: context manager (нет утечек соединений), детект отказов,
  пометка об обрыве ответа
- max_tokens растёт с уровнем детализации (2048/3200/4096)

### 3. Локальный compress
**Файл:** `dndai/scripts/compress.py`
- Сначала эвристика без LLM (мгновенно)
- Фоллбэк на API с fast моделями
- Промпт единый: `prompts/compress.txt` через `api/prompts.py`

### 4. Настройки окружения
**Файл:** `dndai/core/config/settings.py`
- `STREAM_MODE` — по умолчанию ВЫКЛ (сохраняет подсветку разметки); включить: `STREAM_MODE=1`
- `COLOR=1` (по умолчанию) — ANSI цвета, `COLOR=0` — отключить
- Импорт модуля не выполняет сетевых вызовов: модели Ollama-Server
  подгружаются лениво в момент запроса

### 5. Персистентность
**Файл:** `dndai/game/session.py`
- Атомарная запись всех файлов сессии (`core/atomic.py`)
- `schema_version: 2` в JSON; загрузчики толерантны к старым форматам
- Бэкап `.bak` на момент входа + поколение `.bak2`; `!откат` можно
  выполнять многократно за вход (копирование вместо перемещения)

### 6. Правила D&D
- Модификатор характеристики `(значение-10)//2` (floor) — таблица 5e
- Левел-ап: кость хитов класса (среднее, округление вверх) + CON к max_hp,
  лечение на ту же величину; уровень персонажа синхронизирован с Progression
- Крит игрока: удваивает кости оружия, модификатор один раз (RAW)
- Урон по лежащему без сознания = провал спасброска смерти (крит = два)
- Враги: инициатива d20+2; бонус атаки и кость урона масштабируются от max_hp

## Точки входа для расширения

### Добавление новой команды
1. Создайте функцию `(act, ctx) -> CommandResult | None` в `commands/*_cmds.py`
2. Добавьте в `HANDLERS` в `commands/registry.py` (учитывайте порядок!)
3. Добавьте переводы в `dndai/core/i18n.py`

### Добавление нового провайдера
1. Добавьте в `PROVIDER_DEFS` в `settings.py`
2. Добавьте модели в `PROVIDER_MODELS_BY_TIER` в `task_types.py`
3. Добавьте в `TIER_PROVIDER_PREFERENCE` при необходимости

### Изменение моделей
- Отредактируйте `PROVIDER_MODELS_BY_TIER` в `dndai/core/task_types.py`
- Обновите `PROVIDER_DEFS` в `settings.py` для актуальных моделей

## Запуск

```bash
# Обычный запуск (цвета, стриминг выключен по умолчанию)
dndd
python3 -m dndai

# Со стримингом (живой вывод токенов)
STREAM_MODE=1 python3 -m dndai

# Без ANSI цветов
COLOR=0 python3 -m dndai
```

## Известные ограничения

- EN-локаль переводит только UI: игровые команды и LLM-промпты русские
- Лимиты API провайдеров быстро заканчиваются при тестировании
