# D&D КИБЕРПАНК БЕЗ ЦЕНЗУРЫ

Заменяет ДМ-а в фоне: пока запущена программа, подбирает модели в 3х категориях
(умные / средние / быстрые) и ведёт игру.

## Установка (Debian / Ubuntu / Termux)

```bash
git clone https://github.com/Zisvit/Dnd-ai.git Dnd-ai
cd Dnd-ai
./install.sh
```

Скрипт поставит зависимости в `venv/` (см. pyproject.toml) и создаст
команду `dndd`; шаблон ключей появится в `~/.dnd_ai/.env`.

Альтернатива — обычный pip/pipx (venv рядом с проектом не нужен):

```bash
pipx install /путь/к/Dnd-ai   # изоляция, команда dndd в PATH
pip install /путь/к/Dnd-ai    # или в текущее окружение
```

## Запуск

```bash
dndd                 # новая/продолжение сессии "default"
dndd "Имя сессии"    # именованная сессия
dndd --version       # версия (также: python -m dndai)
dndd --copy-prompts  # копия промптов в ~/.dnd_ai/prompts для правки
```

Ключи бот берёт из `.env` рядом с проектом или из `~/.dnd_ai/.env`
(переменные окружения процесса — в приоритете).

Данные (сессии, история ввода, blacklist) живут в `~/.dnd_ai`
(каталог меняется переменной `DND_AI_HOME`); при первом запуске из старой
раскладки репозитория файлы `data/` и `dnd_sessions/` автоматически
копируются туда один раз.

## Команды в игре

- `/help` или `помощь` — справка
- `выход` / `quit` — сохранить сессию и выйти
- `очистить` / `reset` — очистить историю
- `красный` / `жёлтый` / `синий` — переключить категорию модели
- `детальнее` / `короче` — уровень детализации
- `dm: <приказ>` — прямой приказ мастеру
- `/model` / `/model groq[:модель]` — показать/сменить модель или провайдера
- `/models` — модели провайдеров по категориям
- `/stats` или `статистика` — статистика запросов по провайдерам
- `обнови память` — сжать историю и обновить память сюжета

### Механика персонажа (D&D)
- `!персонаж Имя, Класс, HP, КД` — создать персонажа (пример: `!персонаж Волк, Наёмник, 24, 15`)
- `!персонаж Имя | Класс | HP:24/24 | КД:15 | STR:14 DEX:16` — расширенный формат
- `!статус` — показать состояние персонажа
- `!инвентарь добавить "Пистолет", "Аптечка"` — добавить вещи
- `!инвентарь удалить "Пистолет"` — убрать вещь
- `!урон 8` — получить урон
- `!лечение 5` — восстановить HP
- `!hp 20` — установить текущий HP
- `!спас STR 12` — спасбросок (модификатор характеристики учитывается)
- `!бой Моб 15` — атака по мобу (КД 15) + бросок инициативы
- `!кости 2d6+1` — бросить кости (формат `NdM[+K]`)

### Партия (co-op, несколько игроков)
Поддерживается общая партия: каждый игрок управляет своим персонажем, все сохраняются в одной сессии, а записи в журнале помечаются именем активного игрока.
- `!новый Имя, Класс, HP, КД` — добавить союзника в партию (пример: `!новый Маша, Медик, 22, 14`)
- `!персонажи` / `!партия` — список персонажей партии
- `!играть <Имя>` / `!switch` / `!игрок` — переключить управляемого персонажа
- `!переименовать <Имя>` — переименовать активного персонажа

### Мир и локации
- `!мир` — состояние мира (локация, факты, голоса NPC)
- `!идти <<Тёмный переулок>>` — сменить локацию
- `!факт Магия здесь запрещена` — добавить установленный факт мира
- `!голос Бармен циничный` — задать стиль речи NPC (теги: циничный, поэтичный, грубый, детский, учёный, таинственный)
- `!откат` — откатить сессию к сохранению на момент входа (бэкап `.json.bak`)

### RPG-системы

**Заклинания / способности**
- `!закл Имя: Описание | урон 3d6 | СЛ 13` — добавить заклинание
  (лечащие: просто упомяни лечение в описании, например `!закл Малое лечение: исцеляет раны`,
  — `!каст` будет восстанавливать HP и поднимать с 0)
- `!каст Закл [Цель]` — каст (урон по врагу или лечение себя)
- `!ячейки` — остаток ячеек заклинаний
- `!закл` / `!spells` — список; `!закл удалить Имя` — удалить

**Уровни и опыт**
- `!xp 150` — получить опыт (авто-повышение уровня)
- `!лвл` — текущий уровень и прогресс
- `!улучшить STR 1` — потратить очко характеристики (даётся при левел-апе)

**Статус-эффекты**
- `!статус-эффект яд 3` — наложить эффект на N ходов
- `!эффекты` — активные; `!эффект удалить яд` — снять

**Квесты**
- `!квест Имя: Описание` — добавить; `!квест готов Имя` — завершить (+100 XP)
- `!квест удалить Имя`; `!квесты` — список активных и завершённых

**NPC**
- `!npc Имя | голос циничный | заметка | отношение дружелюбно` — добавить
- `!npc` — список; `!npc удалить Имя` — удалить

**Время и погода**
- `!время +3` — сдвинуть время на N часов; `!время` — текущее
- `!погода дождь` — установить погоду (ясно/пасмурно/дождь/туман/снег/гроза/жара/ураган)

**Карта локаций**
- `!карта` / `!map` — показать граф локаций
- `!связь <<А>> <<Б>>` — соединить локации (переходы)

**Журнал**
- `!запись Текст` — добавить запись; `!журнал` / `!дневник` — последние записи

**Макросы**
- `!макрос Имя: команда` — создать (например `!макрос атк: !бой Гоблин 12`)
- `!макросы` — список; `!макрос удалить Имя`
- Набранное слово-макрос раскрывается в команду автоматически

**Тон и жанр**
- `!тон мрачный` — задать тон (мрачный/весёлый/серьёзный/ироничный/жестокий/романтичный/философский/напряжённый)
- `!жанр киберпанк` — задать жанр (нуар/киберпанк/фэнтези/хоррор/вестерн/постапокалипсис/детектив/слэшер)

**Прочее**
- `!тихо вкл` / `!тихо выкл` — скрыть системные сообщения
- `!проверка Утверждение` — сверить утверждение с установленными фактами мира
  (бот также сам отмечает новые факты маркером `[[ФАКТ: ...]]` в ответах)

Состояние персонажа, мир, RPG-системы и память сюжета автосохраняются в сессии.

### Режим эмодзи
- `!эмодзи выкл` / `!эмодзи вкл` — переключить эмодзи в выводе (также `EMOJI=0` в `.env`)

### Стриминг
По умолчанию выключен (сохраняется подсветка разметки). Включить в `.env`:
`STREAM_MODE=1` — живой вывод ответа по токенам.

## API ключи (бесплатные провайдеры)

Бот использует **только реально бесплатные** модели и перебирает провайдеров
при ошибках. Ключи кладутся в `.env` рядом с проектом или в `~/.dnd_ai/.env`:

```
GROQ_API_KEY=gsk_xxxxx          # основной бесплатный провайдер
GEMINI_API_KEY=AQ.xxxxx         # резерв (бесплатный free-tier)
OPENROUTER_API_KEY=sk-or-v1-xxxxx # крайний резерв (:free модели)
```

Достаточно одного Groq, чтобы бот полноценно работал. Неиспользуемые ключи
можно не заполнять. Можно добавить локальный Ollama:

```
OLLAMA_BASE_URL=http://localhost:11434/v1/chat/completions
OLLAMA_MODEL=llama3.2:3b
```

Получить ключи бесплатно:
- Groq: https://console.groq.com/keys
- Gemini: https://aistudio.google.com/apikey
- OpenRouter: https://openrouter.ai/keys

> Together / Fireworks / DeepInfra убраны из конфигурации по умолчанию,
> т.к. их бесплатный доступ недоступен (legacy-ключи, 402, нет моделей).

> Промпты в `dndai/prompts/`; для правки: `dndd --copy-prompts` →
> редактируйте копию в `~/.dnd_ai/prompts/`.
